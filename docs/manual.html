Chapter 1第一次登入

本系統不存放任何密碼，所有身份驗證交由 Cloudflare Access 完成。第一次登入只需要你填入收信的信箱，系統會寄一封一次性密碼信給你。

1.1 開啟系統網址

  1. 在瀏覽器網址列輸入由管理員提供的網域，例如 https://hema.example.com。
  2. 第一次進入會自動跳到 Cloudflare Access 登入畫面 (畫面風格與本系統不同，屬正常)。
  3. 選擇 Send code to your email，填入你被加入白名單的那個 email，然後送出。
注意只有事先被加入白名單的 20 位成員可以登入。如果你輸入的信箱不在名單上，會看到 You do not have access。請聯絡管理員 (見附錄 C)。

1.2 收信並輸入一次性密碼

  1. 查看信箱，找到寄件者為 noreply@notify.cloudflare.com 的信。
  2. 信件主旨類似「Your one-time PIN」，內容會有一組六位數字。
  3. 把這組數字貼回登入頁面，按 Send。
  4. 驗證通過後會自動轉址回系統首頁，看到「早安/午安/晚安 + 你的名字」即代表成功。
小撇步Cloudflare 會在你的瀏覽器留下一段時效約 24 小時的 session，期間內重新開啟系統不用再驗證一次。換瀏覽器、清 cookie、或太久沒登入時才需要再走一次 OTP 流程。

1.3 首次登入後該做的事

  1. 右上點頭像進入 個人資料，把 顯示名稱 改成你想被夥伴看到的名字 (預設是 email 前綴)。
  2. 上傳一張頭像 (任何方形圖檔即可，會自動裁切)。
  3. (選用) 填一段 Bio，讓別人在你留言旁邊看到你是哪個次專科/醫院。
為什麼要設名字你的留言、共筆編輯紀錄、@提及通知都會用這個名字呈現。預設的 email 前綴在共筆協作時辨識度低。

最上方的卡片顯示距離 2026/08/29 (六) 09:00 還剩多少時間，精確到秒。當天數小於 60 變橘色、小於 30 變紅色，提醒自己進入衝刺期。考試當天會切換為「考試已開始 — 加油!」訊息。

題庫的答案不一定無誤，社群可以針對任何一題提出「答案挑戰」。這個區塊聚合最近 8 筆挑戰，狀態標籤如下：

狀態意義

Chapter 4複習模式

複習模式是本系統的核心。一題一答、立即揭曉、共筆詳解、討論串、@提及、收藏、相似題、AI 工具，所有功能都圍繞「同一題」展開。本章依使用順序逐項說明。

4.1 進入複習

  1. 主選單點 複習，進入複習索引頁。
  2. 選一個年度，或從首頁的「年度卡」直接進入。
  3. 在該年的題目列表點任一題編號 (例：113-001) 打開題目頁。
小撇步題目頁底部有 ⟵ 上一題 / 下一題 ⟶ 按鈕，可在同年度連續複習而不用回列表。鍵盤可用 ← → 跳前後題。

4.3 共筆詳解

詳解是 整個團隊共同維護的單一份文件。任何成員都可以編輯，但同一時間只能有一個人在編輯 (悲觀鎖)。

4.3.1 閱讀模式

題目頁的「詳解」分頁預設是唯讀，顯示目前最新版本。內容支援標題、清單、粗體、斜體、行內 code、區塊引用、圖片、@提及、跨題引用、表格。

4.3.2 編輯模式

  1. 確認目前沒有人正在編輯 (沒有「XXX 正在編輯…」橘色橫幅)。
  2. 點詳解區右上的 編輯 (鉛筆 icon)。
  3. 系統會嘗試取得編輯鎖，成功後切到富文本編輯器。
  4. 編輯時頂部會顯示「你正在編輯 · 剩餘 4:58」倒數，每 60 秒自動續鎖。
  5. 編輯完成按 儲存；要放棄按 取消 (鎖會立刻釋出)。
鎖會自動過期若你打開編輯後 5 分鐘沒有任何動作 (沒儲存、沒續鎖)，鎖會自動釋出，其他人即可開始編輯。長時間離開電腦前請先存檔。

4.3.3 版本控制

每次儲存都會把版本號 +1。如果在你儲存前有別人也存了一版 (你會看到衝突訊息)，系統會拒絕你的儲存，請按 重新載入最新版，再把你的修改套上去。

4.3.5 在詳解中插入圖片

  1. 在編輯模式下點工具列的 🖼。
  2. 選擇本機圖檔 (支援 JPG / PNG / WebP，建議 < 2 MB)。
  3. 圖片會上傳到 R2 私有儲存桶並回傳一組 /img/<key> URL，自動嵌入到目前段落。
  4. 儲存後其他成員打開該題即可看到。
隱私所有圖片都會經過 Cloudflare Access 驗證，沒有登入的人即使拿到 URL 也看不到。請放心上傳教科書截圖或自繪示意圖。

4.4 個人筆記

題目頁的第二個分頁 我的筆記 是 只有你自己看得到 的私密欄位。適合放：

  • 還沒成熟、不想公開給團隊的猜想
  • 個人助記詞、口訣
  • 讀書計畫提醒 (例：第二輪要回來看這題)
  1. 切到 我的筆記 分頁。
  2. 直接點內容區進入編輯 (沒有鎖、沒有版本，因為沒有別人會動)。
  3. 編輯完按 儲存。空白即代表你還沒寫過。

4.5 留言與 @ 提及

每題下方有一個討論串，用來針對「這份詳解」展開二級討論：質疑、追問、補充延伸閱讀、貼新文獻等。

4.5.1 發一條留言

  1. 滑到題目頁底部 討論 區塊。
  2. 點 寫留言 開啟編輯框。
  3. 輸入內容 (支援與詳解相同的富文本)。
  4. 按 送出。留言會即時出現在串列頂部。

4.5.2 @ 提及某位成員

  1. 在輸入框任意位置打 @。
  2. 跳出 20 人名單，輸入幾個字即時過濾。
  3. 選中後會插入一個彩色標籤 (例：@小明)。
  4. 送出後，被提及的人會在右上 🔔 收到通知。

4.5.3 回覆別人 (留言串)

  1. 在任一條留言下方點 回覆。
  2. 輸入內容後送出，回覆會縮排到原留言之下。
  3. 系統會顯示兩層；更深的回覆會被收合，點 展開 看全文。
  4. 被回覆的人也會收到 🔔 通知。
使用習慣詳解改錯就直接編詳解 (留版本紀錄)；對「這份詳解的邏輯/結論」有質疑、想討論不確定的地方，就在留言區提出 — 兩者分工會讓共筆內容比討論串清爽很多。

4.6 收藏

  1. 題目頁右上點 🔖 收藏。
  2. 圖示變成實心橘色代表已加入。
  3. 到主選單 收藏 頁可看所有自己標記過的題目。
  4. 再點一次 🔖 即可取消收藏。

4.7 相似題

題目頁中段會自動列出與當前題「最相似」的數題 (依共同 tag 與全文相似度排序)。每筆顯示題號 + 題幹前幾字。

  1. 點任一筆即跳到該題目頁。
  2. 找回頭路靠瀏覽器的 ← 上一頁，或頂欄的麵包屑。
用途題庫中有大量考點重複出現的題目 (例：MGUS vs MM 診斷標準、CAR-T 適應症)。準備同類題時用相似題串著看比直接讀年度更有效率。

4.8 AI 摘要與翻譯 (選用)

若詳解內容偏長或內含大量英文，題目頁有兩顆按鈕：

按鈕效果
✨ 摘要用 Workers AI 跑出 200 字內的中文重點。
✨ 翻譯把詳解全文翻成中文。
  1. 點按鈕，下方面板顯示「處理中…」。
  2. 結果出現後即可閱讀，按 ✕ 關閉面板。
  3. 若詳解版本被更新，舊摘要會自動失效，再按一次重新生成。
用量限制AI 是 Cloudflare 免費額度，每天上限 10,000 neurons。團隊整體大量使用可能跑完額度；發現「處理失敗」時可隔日再試。

4.9 答案挑戰

這是本系統最具特色的功能。考古題的官方答案偶爾有錯，本流程讓任何成員都能正式發起挑戰，經多數同意後改寫題庫的官方答案。

4.9.1 提出挑戰 (filing)

  1. 確認你已經作答過該題 (沒答過無法挑戰)。
  2. 滑到題目頁的「答案揭曉」區塊下方，點 提出答案挑戰。
  3. 從可選字母中挑出你主張的正確答案 (不能選與目前官方答案相同)。
  4. 寫一段論述 (建議附文獻 PMID 或教科書頁數)。
  5. 送出後狀態變 表決中，全題庫的「近期答案挑戰」會出現你的這筆。

4.9.2 投票表決

  1. 看到別人提出的挑戰時，閱讀對方論述。
  2. 點 ✓ 同意 或 ✗ 反對。
  3. 投錯了還可以 收回投票 重投。
  4. 提案人不能投自己的挑戰。

4.9.3 結案

條件狀態結果
同意 ≫ 反對已採納題目官方答案被改寫為提案答案，挑戰紀錄保留。
反對 ≫ 同意已駁回官方答案維持，挑戰封存。
持續有反對票討論中需要在留言區補充證據後重新表決。

4.9.4 撤回挑戰

若你在發出挑戰後又改變主意，可以從題目頁的挑戰橫幅按 撤回挑戰。撤回後該挑戰會被歸檔，他人不再看到。

Chapter 5全真作答

全真作答是把你關進跟真實考場一樣的情境：100 分鐘、100 題 (內科 70 + 共同 30)，連續作答中途不揭曉答案，做完才看總分與錯題回顧。考前一個月強烈建議至少做完三套。

5.1 啟動一場全真

  1. 主選單點 全真。
  2. 選擇科別：內科 (70 題) 或 共同 (30 題)。預設兩者都選 (= 完整 100 分鐘)，但你也可以只練其中一塊。
  3. 從年度卡 (104–113 + 100 模擬) 點任一年即開始。
  4. 系統會隨機抽題、計時器立刻啟動。

5.3 中途暫停與續答

  1. 按 ⏸ 暫停，題目隱藏、計時凍結。
  2. 瀏覽器可以關掉、可以登出。session 一直保留。
  3. 下次回到 全真 主畫面，會看到「上次未完成的考試」橫幅，點 續答 從原本的題號繼續。
  4. 按 ▶ 繼續 恢復計時。
不要硬關不按暫停就關瀏覽器，下次回來時間是繼續走的 (因為 server-side 時間戳沒停)。模擬考想盡量逼近真實，但忘了真的會被扣時間。

5.4 交卷與結果頁

  1. 所有題目作答完或時間到，自動跳轉到 結果頁。
  2. 頁面顯示：總分 (例：72/100)、內科分數、共同分數、平均每題用時。
  3. 下方逐題列出「你的答案 / 正解 / 對錯」，點任一題進入該題的複習頁 (此時詳解、留言、收藏功能都可用)。
  4. 所有錯題會自動加入 錯題 清單 (第六章)。

5.5 歷次紀錄

主選單沒有「全真紀錄」入口，但結果頁、全真起始頁、首頁底部都有 → 查看歷次作答紀錄 連結。紀錄頁列出每一場：日期、年度、分數、用時，點任一場可重新看結果頁。

Chapter 6錯題回顧與作答紀錄

錯題與作答紀錄是「考前最後一週」的核心戰場。錯過的題目永遠比沒看過的題目值得再看一次。

6.1 錯題清單

主選單點 錯題。系統列出所有「最近一次作答答錯」的題目，依年度反向排序。

  1. 點任一題的題號進入題目頁。
  2. 重新作答；若這次答對，該題會自動從錯題清單移除。
  3. 過濾器可選「依年度」、「依科別 (內科/共同)」收斂範圍。
複習節奏第一週：把所有錯題答對一次。第二週：間隔一週再做一次同一批，仍答錯的代表觀念真的還沒抓到，去翻教科書。

6.2 作答紀錄

作答紀錄 列出你跑過的每一場全真，可以看分數趨勢。對自己負責的最低標：考前一個月內至少跑兩場分數 ≥ 70 的全真。

Chapter 7搜尋、收藏與快速跳轉

7.1 全文搜尋

  1. 主選單點 搜尋。
  2. 輸入關鍵字 (中英皆可)，例如 CAR-T、MGUS、thrombocytopenia。
  3. 結果顯示符合的題目，命中字會反白；點任一筆進入。
  4. 可同時搜題幹、選項、詳解、留言。
進階用法用引號 "acute lymphoblastic leukemia" 搜整個短語；用空格分隔多個關鍵字代表 AND；想搜縮寫又怕誤判，可拉長為 chronic myeloid leukemia OR CML。

7.2 收藏清單

主選單 收藏。所有你按過 🔖 的題目都在這裡，依加入時間排序。可用於：

  • 標記「考前一定要再看」的題目
  • 整理「特定主題」(例：用收藏 + 自己的個人筆記做出血液病急症題組)
  • 標記「想找時間幫詳解擴寫」的題目

7.3 在詳解內跨題引用

  1. 編輯詳解時，在編輯框任意位置打 @。
  2. 除了成員名單之外，輸入 113-001 這類題號格式也會出現「跨題引用」選項。
  3. 選中後會插入一個 ↗ 113-001 小膠囊。
  4. 讀者點擊即跳到該題。

Chapter 8個人資料與通知

8.1 編輯個人資料

  1. 右上點頭像 → 個人資料。
  2. 修改 顯示名稱 (留言、@提及、共筆編輯紀錄都會用這個)。
  3. 修改 Bio (一兩句自我介紹)。
  4. 按 儲存。畫面右上會閃 已儲存 提示。

8.2 換頭像

  1. 頁面左上角的頭像區塊點 換頭像。
  2. 選一張本機圖檔 (建議方形，JPG / PNG，<2 MB)。
  3. 上傳完成後即時生效，所有頁面同步更新。

8.3 通知中心

右上 🔔 是你會收到通知的地方。觸發條件：

  • 有人在留言/詳解 @ 提及你
  • 有人回覆你的留言
  • 你提出的答案挑戰被採納/駁回
  • 你投了反對票的挑戰結案 (採納 or 駁回)
  1. 有未讀時 🔔 出現紅點。
  2. 點開鈴鐺看清單，每筆顯示「誰、在哪一題、做了什麼」。
  3. 點任一筆跳到該題對應位置 (留言會自動 scroll 到該則)。
  4. 點 全部標為已讀 一鍵清空紅點。

8.4 線上使用者

頂欄的「線上 (N)」會顯示目前同時開著系統的成員數量，hover 看頭像清單。考前一週這個數字會明顯變高 — 善用這時候在留言區發問，回應通常很快。

8.5 意見回饋

  1. 頂欄的 💬 按鈕。
  2. 填寫遇到的問題或想要的功能，會自動帶上你目前所在的網址、瀏覽器版本。
  3. 送出後會建立一個 GitHub Issue 到專案 repo。
  4. 後續進度可由系統管理員追蹤。

Appendix B常見問題 FAQ

Q1. 我忘記了上次的密碼怎麼辦?

本系統 沒有密碼。所有登入都靠 Cloudflare Access 寄到信箱的一次性密碼。如果新裝置或新瀏覽器要登入，照第一章流程跑一次即可。

Q2. 為什麼我編輯詳解到一半，按儲存出現「衝突」?

在你開啟編輯到按儲存的這段時間，有別人也存了一版。請按 重新載入最新版，把對方的內容讀回來，再把你的修改重新加上去存。鎖無法 100% 避免這個 race，因為鎖會在 5 分鐘無動作時自動釋出 — 這是設計上故意的，避免有人卡住整個共筆。

Q3. 我能不能刪掉自己的留言?

可以。留言旁的 ⋯ 選單有 刪除。已被回覆的留言刪除後會顯示「(已刪除)」，保留結構但隱藏內容，避免破壞討論串。

Q4. 我發現某一年的某一題題幹有錯字，怎麼修正?

題幹屬於官方考古題，原則上 不修改 (保留原始紀錄)。請在留言區指出錯字，或在詳解開頭寫一行「題幹原文 OCR 有誤，正確應為 ...」。如真是嚴重影響理解的錯誤 (例：選項抄錯)，請從 💬 提交意見回饋給管理員處理。

Q5. 我答錯了一題，能不能不要被加進錯題清單?

不能直接排除，但若你之後再答對一次，該題會自動移出。錯題的設計就是讓你誠實面對自己。

Q6. 全真作答跑到一半網路斷線，紀錄會掉嗎?

不會。每次選答案、暫停、跳題都會即時 sync 到 server。網路恢復後重新進入 全真，按 續答 即可從原本的狀態回到考場。

Q7. 我可以用手機作答嗎?

可以。所有頁面都是 RWD 設計。但 長詳解的閱讀體驗 在桌機/平板會明顯更好；全真作答強烈建議桌機，避免手滑誤點。

Q8. AI 摘要按了沒反應?

可能原因：(a) 當天團隊 AI 額度用完；(b) 詳解內容過短不夠摘要；(c) 暫時的 Worker 故障。請隔 30 分鐘再試，或從 💬 回報。

Q9. 答案挑戰被駁回後，我能再提一次嗎?

可以，但建議先在留言區補上新的證據再開新挑戰，否則容易被同樣的票數再次駁回。挑戰歷史會永久保留 (採納/駁回都看得到)，所以「挑戰失敗」不是負面紀錄，是知識協作的痕跡。

Q10. 我能匯出自己的進度、錯題、筆記嗎?

目前還沒有 UI 匯出按鈕，但你的所有資料都安全保存在 D1 資料庫中。考完試後若需要備份，可向管理員索取。

Appendix C回報問題與聯絡

C.1 我發現了系統 Bug

  1. 頂欄點 💬 意見回饋。
  2. 選擇 Bug 回報。
  3. 盡量描述：(a) 我做了什麼 (b) 我預期看到什麼 (c) 實際看到什麼 (d) 重現步驟。
  4. 如方便附截圖請拖入。
  5. 送出 — 會自動建立 GitHub Issue。

C.2 我有功能建議

同樣從 💬 進入，類別選 功能建議。受歡迎的建議會被排進系統路線圖。本系統故意維持小巧：建議「合作學習相關」的功能比「個人化炫技」的功能更容易被採納。

C.3 我想加入新成員 / 移除成員

請聯絡管理員處理 Cloudflare Access 白名單。新成員加入後需要：

  1. 提供其 email 給管理員加入 Access 名單。
  2. 請他/她按第一章的流程登入。
  3. 登入後系統會自動 upsert 為一位成員。
  4. 提醒他/她到個人資料設好顯示名稱與頭像。

C.4 我想看完整文件 / 原始碼

本系統為內部協作工具，部分文件 (架構、部署、資料庫 schema) 放在專案的 README.md 與 CLAUDE.md。需要技術細節時可向管理員索取 repo 權限。
