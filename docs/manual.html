Chapter 1第一次登入

本系統不存放任何密碼,身份驗證全部交給 Cloudflare Access。第一次登入只需要填入被加入名單的信箱,系統會寄一封一次性密碼信給你。

1.1 開啟系統網址

  1. 在瀏覽器輸入管理員提供的網址。未登入時會看到對外頁:站名、登入 按鈕,以及三張功能卡(共筆詳解 / 全真模擬 / 答案挑戰)。
  2. 按 登入,會跳到 Cloudflare Access 的登入畫面(風格與本系統不同,屬正常)。
  3. 填入你被加入白名單的 email,送出。
注意只有事先被加入白名單的成員可以登入。信箱不在名單上會看到 You do not have access,請聯絡管理員(見附錄 C)。

1.2 收信並輸入一次性密碼

  1. 查看信箱,找到寄件者為 noreply@notify.cloudflare.com 的信,內含一組六位數字。
  2. 把數字貼回登入頁面送出。
  3. 驗證通過後自動轉回系統首頁,看到「早安 / 午安 / 晚安 + 你的名字」即代表成功。
小撇步Cloudflare 會在瀏覽器留下一段 session,期間內重新開啟系統不必再驗證。換瀏覽器、清 cookie 或太久沒登入時才需要再走一次 OTP。

1.3 首次登入後該做的事

  1. 右上點頭像進入 個人資料,在「基本資料」把 顯示名稱 改成你想被夥伴看到的名字(預設是 email 前綴)。
  2. 按 更換頭像 上傳一張圖(最大 2 MB,自動裁切)。沒上傳時系統會依你的 email 固定指派一隻動物頭像,每台裝置看到的都一樣。
  3. (選用)填 個人簡介,例如「Fellow 2, 某某醫院」。
  4. 按 儲存,左側出現「✓ 已儲存」。
為什麼要設名字留言、共筆編輯紀錄、@提及通知、聊天大廳、線上名單都用這個名字呈現;預設的 email 前綴辨識度低。

系統有一條跨頁固定的頂欄、隨螢幕寬度收放的導覽、右上角一排狀態工具,以及手機專用的底欄。把這幾個區塊看熟,後面的章節都會更直觀。

2.3 手機底欄

寬度小於 768px 時頂欄的導覽隱藏,改由底部五顆取代:首頁 複習 全真 搜尋 收藏。目前部署以抹片練習為主力,所以後四顆指向抹片:「複習」開抹片的主題選擇頁、「全真」直接跳出開始練習對話框、「搜尋」與「收藏」是抹片頁的對應分頁。筆試側的入口在首頁「筆試」分頁與各頁的捷徑列。

2.4 浮動按鈕

  • 番茄鐘(右下角,每一頁都有):點開可選 專注 / 短休息 / 長休息,按 開始 後圓鈕變成倒數與進度環。齒輪可設專注時長、休息長度、自動接續、提示音與瀏覽器通知。面板裡有一條 玩 2048 連結,休息時段會放大提示。
  • 回到最頂(左下角):只在題目頁、且手機寬度捲過 400px 後出現。
  • 手把操作說明(左下角):接上遊戲手把後才出現,見 §12.5。

2.5 離線橫幅與新版本提示

斷線時頂欄下方會出現一條細長的 離線中 · 可閱讀已看過的內容,編輯功能暫停,恢復連線就消失。有新版本部署時會出現 有新版本可用,按 重新載入 更新;不想中斷可按 稍後。

Chapter 4抹片練習

專科考試的抹片題是填空,不是選擇:認得出 dacrocyte 但寫成 dacrocite 在考卷上是 0 分。抹片練習讓你看一張血液抹片、把診斷拼寫出來,並且區分「認得出」與「寫得出」兩種能力。它跟筆試題庫完全分開——自己的題庫、作答記錄、搜尋與統計。

4.1 抹片練習首頁

頂欄 抹片(或首頁抹片分頁的入口)進入 /smear。頁面有六個分頁:練習 作答記錄 錯題本 搜尋 已收藏 投稿。分頁狀態寫進網址,可以直接加書籤。

4.2 素材與主題

題庫有三種題源,開場時可勾選:歷屆考題(203 題,四份官方答案卷逐頁擷取)、ASH 影像庫(ASH Image Bank 的補充圖,附出處連結)、社群投稿(成員上傳、管理員核准後加入)。所有圖對應到 103 個診斷,分成七個主題:骨髓性 · 淋巴性 · 正常 / 反應性 · 紅血球系 · 血小板 / 巨核系 · 感染相關 · 其他。每個診斷都有共筆詳解與「容易混淆的」相關診斷。

複習模式的主題選擇頁

點 全部主題 或任一主題卡,會開啟開場設定並預選該主題。

4.4 開場設定

  1. 模式:複習模式 或 全真模式。
  2. 題數:5–200,預設 50。抽題會依主題在題庫的比例分層,並盡量避開上一場考過的圖。
  3. 作答寫法:任意寫法 / 只收全稱 / 只收縮寫。
  4. 主題篩選:七個主題可複選(至少一個),旁邊標示各主題佔題庫的百分比。
  5. 題源:歷屆考題 / ASH 影像庫 / 社群投稿,預設全勾。
  6. 按 開始練習。組合抽不到題時會提示放寬篩選。
作答寫法目前只是記錄這個選項會存在這場的設定裡,但判定仍同時接受全稱與縮寫。真的要練「只寫全稱」,請自我要求。

4.5 作答頁

  • 圖片:點一下全螢幕放大(長邊 2400px),雙指縮放走瀏覽器原生手勢,Esc 或點空白處關閉。圖左上角的 複製圖片 把圖放進剪貼簿,方便貼到筆記或問 AI。
  • 題幹:What cell? 或 What disease?;有些圖附一行 A / B 標註說明。
  • 怎麼判讀?:可摺疊的判讀骨架(細胞辨識五個觀察點 / 紅血球形態五個觀察點 / 疾病診斷三步驟),不含任何診斷專屬資訊。
  • 輸入框:單一自由輸入,不顯示格數(格數會洩漏答案長度)。手機鍵盤的自動校正、自動大寫已關閉,Döhle、Auer rod 不會被改掉。Enter 或 提交答案 送出。
  • 提示:顯示「分類提示:{主題}」。用過提示會被記錄下來(不影響分數)。
  • 不會嗎?直接看答案(只有複習模式):算 0 分,但顯示正解與詳解。
  • 底部 上一題 / 下一題,最後一題變 查看成績;提前結束 會確認「還有 N 題未作答」。

4.6 判定:四層,拼字錯不扣分

判定分數意義
✓ 完全正確1寫出標準全稱、縮寫或其他同義正式寫法(例:dacrocyte / dacryocyte)。
◐ 部分正確(半分)0.5方向對但不夠精準(例:poikilocytosis 之於 dacrocyte;Plasma cell 之於 Plasmoblast)。
~ 俗名用法(不計分)0tear drop、burr cell、smudge cell 這類俗名。考卷不收,所以不給分,但明確告訴你正解,並單獨統計「用了俗名 N 題」。
✗ 未命中0沒對上任何可接受寫法。
  • 拼字容錯:長度 ≥5 的字允許差 1 個字母,仍給該層滿分,另外顯示「拼字提醒」並計入「拼字完全正確」統計。三字母縮寫(AML / ALL)不容錯——差一個字母就是另一個病。microcytic / macrocytic、hypo- / hyper- 這類臨床意義相反的字對也不容錯。
  • 比對前會統一大小寫、去變音符與連字號(Pelger-Huët = pelger huet)。
  • 可接受的寫法 列出該診斷所有被收錄的寫法,前綴 ✓ / ◐ / ~ 對應上表三層。
  • 不是完全正確時,判定卡下方提示「往下看『詳解』的容易混淆處,或切到『相似』分頁比較」,接著是四個面板:詳解 個人筆記 討論 相似(內容同 §4.8 的診斷詳情頁)。

4.7 成績頁

  • 分數 / 滿分與百分比,加上 拼字完全正確:N 題、用了俗名:N 題。
  • 主題分類:這場出現過的每個主題一條進度條,右側得分 / 滿分。
  • 再練一次(同模式)、查看作答記錄,以及 只針對答錯的 N 個主題再練一次(複習模式)。
  • 逐題檢討:篩選 全部 / 待加強(非完全正確都算);每列有縮圖、判定、你的作答、正解(可點進診斷詳情)、拼字提醒。
全真模式中途看不到成績還沒交卷就把網址改成 /result 會被導回作答頁;作答記錄裡未完成的場次也只顯示「未完成 · 點擊繼續作答」,不顯示分數。

4.8 診斷詳情頁與「這個寫法也該算對?」

從成績頁的正解、錯題本、搜尋或收藏都能進入 /smear/dx/…。頁面內容:

  • 標題(全稱 + 縮寫)、主題與題型徽章(細胞辨識 / 疾病診斷)。
  • 影像(N):同一診斷的所有圖;ASH 來源附出處與外部連結。
  • 詳解:共筆詳解固定五段——一句話 / 怎麼認 / 容易混淆的 / 臨床脈絡 / 拼字提醒,「怎麼認」附一段考卷上可以直接寫的英文形態描述。下方是 可接受的寫法 清單。
  • 個人筆記:僅你可見,一個診斷可寫多則,新增筆記 / 編輯 / 刪除。
  • 討論:針對這個診斷的留言串,可回覆;自己的留言可刪。
  • 相似:容易混淆的診斷,點擊互跳。

提報一個新的寫法

  1. 在詳解面板最下方「這個寫法也該算對?」填入 寫法、選 該算幾分(全分 / 半分 / 俗名(不計分))、全稱還是縮寫,理由選填。
  2. 按 送出提報,提報會出現在下方投票清單,狀態 投票中。
  3. 其他成員按 同意 或 反對(可改票、可收回);提報人不能投自己的。
  4. 累積 3 票 且同意多於反對 → 已通過,立刻成為可接受寫法;反對 ≥ 同意(含平手)→ 未通過。結案後不再翻案,也不追溯改已經判過的分數。
重複提報同一個寫法已是可接受寫法、或正在投票中,系統會擋下並提示「幫它投一票就好」。

4.9 搜尋、作答記錄、錯題本、已收藏

  • 錯題本按診斷聚合,不按圖:同一個診斷不管答錯幾張圖都是一列,顯示答錯次數與最近一次日期,錯最多的排最前。「錯」的定義是非完全正確(半分、俗名、未命中都算)。頂端的 針對這 N 個主題再練一次 直接開複習模式。
  • 已收藏:在診斷詳情頁右上角按書籤收藏;最近收藏的排前面。

4.10 投稿

  1. 切到 投稿 分頁,按 點擊選擇圖片(相機或相簿)(JPEG / PNG / WebP / GIF,10 MB 以內)。
  2. 填 正確答案(必填)與文字說明(選填),按 送出投稿。
  3. 下方「我的投稿紀錄」顯示狀態:審核中 → 已核准(進入抽題池)或 已退件(附審核意見)。

管理員在同一分頁多一個 待審核 子分頁:系統會依你填的答案猜一個現有診斷供 採用建議,也可搜尋改選,然後 ✓ 核准 或 ✗ 退件(可附退件原因)。核准前的圖只有投稿人與管理員看得到。

抹片練習不做間隔複習、也不支援離線抹片的統計與筆試完全分開:不進首頁熱圖、不進弱點地圖,也沒有 FSRS 排程。離線時抹片頁無法使用。

Chapter 5筆試複習模式

一題一答、立即揭曉、共筆詳解、個人筆記、討論串、相似題、答案挑戰,所有功能都圍繞「同一題」展開。本章依使用順序逐項說明。

5.1 進入複習與年度清單

  1. 頂欄 複習(或首頁筆試分頁的 複習模式 卡)。頁面有 隨機抽一題開始、「今天 N 張到期」的入口、信心校準區與 弱點概念地圖 →。
  2. 在「選擇年度 (民國)」點一年,進入該年清單:標題「民國 113 年 · N 題」,右上有 匯出 與 Anki FSRS(該年的到期與新卡數)。
  3. 清單可依科別與作答狀態(全部 / 已作答 / 未作答 / 答對 / 答錯)篩選,並用「篩選題號、關鍵字…」即時過濾。每列標示上次答對 ✓ / 答錯 ✗ 與收藏徽章。
  4. 點任一題開啟題目頁。
離線備用進年度清單時,系統會在背景把這一年的題目與詳解拓進離線快取,標題旁顯示「離線備用中… n/N」→「✓ 可離線閱讀」。圖片體積大,要另外按 連圖片一起離線備用。詳見 §12.2。

5.2 題目頁版面

  • 桌機(≥768px) 預設雙欄,中間分隔線可拖曳調整寬度(雙擊還原)。右上角的檢視切換或 t 可改成分頁式。
  • 手機 一律分頁式:題目 詳解 個人筆記,其餘(討論串 / 相似題目 / 影片)摺進 ⋮。切分頁會捲回頂端;換題會重設回「題目」,避免一進下一題就看到詳解。
  • 頁首:回年度清單、上一題 / 下一題(從搜尋進來時是「上一個 / 下一個結果」)。下一題會預先抓好,換題幾乎不等待。

5.3 作答與作答信心

  1. 讀題幹。題幹中的否定詞(wrong / incorrect / except / is not / 錯誤 / 不正確 / 何者非…)會標紅加粗,免得整題讀完才發現問的是「何者錯誤」。
  2. 點一個選項,或按 A–E(再按一次取消)。
  3. 選了選項後出現 作答信心: 猜 / 普通 / 有把握,預設「普通」。信心會進「信心校準」與答題狀態分析,幫你看出「有把握卻答錯」的盲點。
  4. 按 提交答案(或 Enter)。不想作答可按 略過 / 直接看答案(或 Space)。
  • 可以重複作答,每次都會記進歷史;清除本題作答紀錄 只清你自己的。
  • 右上角 複製為 Markdown(或 y)把題目與選項複製成文字,方便貼給 AI 或筆記軟體。
  • 離線或送出失敗時會提示「這次作答沒有記錄成功(可能離線)」;作答本身會排進佇列,連線後自動補送(§12.2)。

5.4 詳解共筆

詳解是整個團隊共同維護的一份文件。作答前它被防劇透遮罩蓋住,要按 點擊顯示詳解 才看得到。

編輯

  1. 確認沒有「XXX 正在編輯…」的標示,按 編輯(離線時不能取得鎖)。
  2. 頂端顯示「✓ 你正在編輯 · 鎖至 HH:MM:SS · 目前版本 vN」。鎖每 60 秒自動續,5 分鐘沒動作會釋出。
  3. 編輯器支援標題、清單、粗體、引用、程式碼、表格、貼上圖片、@ 提及成員、@114 引用題目,以及 匯入 OpenEvidence 連結(把一則已設為公開的 OpenEvidence 對話讀進來)。
  4. 按 儲存。若別人在你之前存了一版,會看到「版本衝突:伺服器已是 vN,你編輯的是 vM。請取消並重新載入。」——按取消、重載、再把你的修改套上去。

沒送出的內容會留成草稿,下次進來看到「↺ 有未送出的詳解草稿——點『編輯』繼續」。詳解底部顯示最近更新者、時間、版本與「N 人共筆 · 第 M 版」。

自動挖空與防劇透

  • 自動挖空:AI 從詳解挑出關鍵詞當空格;再按一次移除。內容太短或這次挑不出來會直接告訴你。
  • 防劇透:遮住你的螢光標記與自動挖空的關鍵詞,逐個點擊揭曉,拿來自我測驗。

OpenEvidence

詳解分頁右緣的 OpenEvidence 把題幹與選項(不含正解)丟到 OpenEvidence 新分頁,可當盲解參考。

5.5 個人筆記

個人筆記 分頁只有你自己看得到。一題可以有多則筆記:

  • 頂端的切換器顯示「標題 n/N」,左右箭頭換筆記;下拉清單可用握把拖曳排序(兩則以上才出現),底部 新增筆記。
  • 手機上在筆記卡左右滑動換上一則 / 下一則(不是換題);表格或程式碼區塊可橫捲的地方不會誤觸。
  • 全螢幕 把筆記卡放大到整個視窗,Esc 離開。自動挖空 / 防劇透 / 編輯 三顆在窄螢幕收進 更多。
  • 編輯時可貼圖、@114 引用其他題、匯入 OpenEvidence 對話(可勾「一則回答存一則筆記」)。n 直接跳到筆記並開始編輯。
  • 筆記內的標題會收成手風琴,方便長筆記導覽。

5.6 螢光畫記與選字工具列

在詳解、個人筆記、其他筆記或講義上選取文字,會浮出一條工具列(依情境顯示):

按鈕作用
螢光標記 / 清除標記畫記或清掉。畫記存在伺服器,所有裝置同步;收藏頁的「我的畫記」可總覽。
查參考資料選取 ≥3 字,到 Wintrobe 教科書與複習班講義的全文索引找相關段落,附深連結跳到那一頁。

5.7 討論串與 @ 提及

  1. 切到 討論串,點看起來像輸入框的「寫下你的想法,@提及其他成員…」展開編輯器。
  2. 打 @ 挑成員;@114 開頭則是引用題目。按 發表。
  3. 留言下方 回覆 可縮排回覆,最多三層;自己的留言可 編輯 / 刪除。
  4. 覺得某則留言有幫助,按「這則留言幫到我了」的按鈕;多於一則時可切換 依時間 / 最有幫助。

被提及、被回覆、被標記有幫助的人都會收到通知(§11.7)。

分工詳解改錯就直接編詳解(留版本);對詳解的邏輯有疑問就在討論串提;認為官方答案錯了就發起答案挑戰(§5.10)。

5.8 相似題目與影片

  • 相似題目:語意相似(向量)、共用標籤、文字相似三種來源。開始交錯練習 把這些跨年份的相近題混在一起連續做(interleaving)。「被引用」區列出哪些詳解或留言引用了本題。
  • 影片:依本題標籤對到影片庫的教學影片;覺得不好可以從卡片右上角移除(全站生效,影片庫可還原)。

5.9 收藏與資料夾

題目卡右上角的書籤圖示收藏本題(揭曉後也可按 b);右鍵可選資料夾、新增資料夾或取消收藏。收藏總覽見 §8.4。

5.10 答案挑戰

考古題的官方答案偶爾有錯。任何成員都可以在作答後發起挑戰,由社群投票決定是否改寫題庫答案。

  1. 作答揭曉後,題目卡下方按 🤔 對答案有疑問?發起挑戰。
  2. 選「主張答案應為」哪個選項,填理由(必填;歡迎附指引、文獻),按 發起挑戰。
  3. 其他人看到橫幅「某人主張正解應為 X (原 Y)」與 表決中,可按 同意挑戰 / 反對,投錯可 撤回投票。提案人可 編輯理由 或 撤回挑戰。
狀況結果
2 位同意、0 反對立即 已採納:題庫答案改寫,題目卡留下「由社群修正:Y → X」的紀錄與理由。
出現任何反對票進入 討論中,至少 48 小時後、同意 ≥4 且淨票 ≥+3 才採納。
淨票 ≤ −2已駁回。

沒有人工「結案」按鈕——全部由票數與時間自動判定。結果出爐時相關成員會收到通知。所有挑戰的總表見 §8.5。

Chapter 6今日複習(間隔複習)

系統用 FSRS 演算法替每一題安排下次複習的日期。首頁與複習頁的「今天 N 張到期」就是入口,做完今天的份就好,不必追。

  1. 頂端顯示「今天 N 張」與三種來源:到期(排程到今天的)、學習中(剛評過「重來 / 困難」、幾分鐘後要再看的)、新卡(還沒學過的,每天最多 20 張)。
  2. 讀題、心中作答,按 顯示答案。
  3. 依回想的難易按 重來 / 困難 / 良好 / 簡單;每顆下方預告下次間隔(現在 / N 分 / N 小時 / N 天)。卡片右上角的「R N%」是預估的記憶保留率。
  4. 做完顯示「今天的複習做完了」與下一張的時間;新卡額度用完會另行提示。
一天從凌晨 4 點算起熬夜到兩點做的仍算「今天」,四點後才換日。年度清單右上的 Anki FSRS 可只做某一年的到期卡。
離線到期佇列需要伺服器排程,離線時打不開。一般複習模式的作答離線時會先排隊,連線後自動補送。

Chapter 7全真作答

把自己關進跟考場一樣的情境:每題 1 分鐘、內科 70 + 共同 30 共 100 題、中途不揭曉,做完才看總分與錯題。考前一個月建議至少完成三套。

7.1 年度卷

  1. 頂欄 全真。副標顯示「100 分鐘模擬考」;可在「科別」只勾其中一科,時限依題數等比縮短(每題 1 分鐘)。
  2. 點任一年度卡,系統建卷、計時立刻開始。
  3. 有進行中的考試時,頁面頂端會出現「進行中的模擬考」膠囊,點擊續答。

7.2 自訂測驗

全真頁的 自訂測驗 卡(或複習頁的「自訂一份測驗」)可以自己出一份卷:

條件選項
題目狀態未做過 最近答錯 已收藏 曾答對(複選是聯集;不選 = 不限)
年度 / 科別 / 主題 tag不選 = 全部;tag 多選是「或」
題數1–100,預設 20
模式計時(每題 1 分鐘,歸零自動交卷)或 不計時;考試模式(全程不揭曉)或 教學模式(每題作答後立刻看答案與詳解,不可改答)

從搜尋結果按「把這 N 題出成測驗 →」或錯題回顧按「把這些出成一份測驗 →」進來時,會先鎖定那批題目再套用上面的條件;想放開可按 改用全題庫。

7.4 交卷確認

  • 還有未答題:先列出 未作答 · 點題號回去作答 與 已標記待檢查 的題號,主按鈕是 回去作答;堅持要交按 仍要交卷,會再問一次「這 N 題會以 0 分計算」。
  • 全部答完:只問一次「確定要交卷?」,再檢查一下 或 確定交卷。

7.5 成績頁

  • 分數、百分比(≥60% 綠)、用時與日期;右上 匯出 / 只匯出答錯的。
  • 登記進複習進度:這場考對、但複習進度還記著舊答案的題目,按 全部登記 (N) 一次搬過去,之後不會再被當成錯題丟回來。考錯的不動。
  • 配速:前半段 / 後半段平均用時、後段慢了幾 %、最慢五題。
  • 篩選 答錯/未答 答對 標記 全部;展開全部選項 顯示每題的選項全文、正解、你選的與全體選項分布。
  • 每列滑過去有 在新分頁開啟 與 查看詳解(不離開清單,彈出詳解)。

7.6 作答紀錄

全真頁底部的 → 查看歷次作答紀錄 或首頁捷徑「作答紀錄」。每列列出年度(自訂卷標「自訂」與篩選條件)、開始時間與分數;點擊回成績頁。右側可刪除單筆紀錄。

Chapter 8錯題、搜尋、弱點地圖、收藏與答案挑戰清單

8.1 錯題回顧

頂欄 錯題:列出最近一次作答答錯的題目。可依年度、科別、tag 篩選;排序有 按錯誤率排序 / 按答錯次數排序 / 最近做過的排前面 / 最久沒做的排前面 / 按題號排序。把這些出成一份測驗 → 直接送進自訂測驗。再答對一次的題目會自動移出。

8.4 我的收藏

8.6 匯出

Appendix B常見問題 FAQ

Q1. 我忘記密碼怎麼辦?

本系統沒有密碼。新裝置或新瀏覽器要登入,照第一章流程收一次信箱驗證碼即可。

Q2. 編輯詳解到一半,按儲存出現「版本衝突」?

在你開啟編輯到儲存之間,有別人存了一版。按取消、重新載入把對方的內容讀回來,再把你的修改套上去。你的內容會留在草稿裡,不會不見。鎖在 5 分鐘無動作後會自動釋出,這是刻意的,避免有人卡住整份共筆。

Q3. 抹片練習我明明寫對了,為什麼只有半分或 0 分?

看判定卡下方的「可接受的寫法」:◐ 是方向對但不夠精準,~ 是俗名(考卷不收)。拼字差一個字母不扣分,會另外顯示「拼字提醒」。如果你認為某個寫法應該算對,到診斷詳情頁的「這個寫法也該算對?」提報,3 票通過就會收錄。

Q4. 全真模式的抹片練習,中途想看分數?

不行,全真模式藏到交卷為止;作答記錄裡只顯示「未完成 · 點擊繼續作答」。想邊做邊看請用複習模式。

Q5. 我答錯了,能不能不要進錯題?

不能直接排除,但再答對一次就會自動移出。模擬考考對的題目,可在成績頁「登記進複習進度」一次搬過去。

Q6. 全真作答跑到一半斷線,紀錄會掉嗎?

不會。每次選答案、暫停、跳題都即時同步到伺服器。恢復連線後回到全真頁,按「進行中的模擬考」續答。注意時間是伺服器算的,沒按暫停就會一直走。

Q7. 為什麼今日複習說「今天沒有到期卡片」,可是我很久沒做了?

只有在複習模式作答過(或在今日複習評過分)的題目才會進 FSRS 排程;新卡每天最多 20 張。一天從凌晨 4 點算起。

Q8. 換手機後,我的畫記、筆記、收藏還在嗎?

都在伺服器上,登入即同步。只有主題、強制手機版面、AI 金鑰這類裝置偏好存在本機。

Q9. 頁面顯示怪怪的,無痕視窗卻正常?

這台裝置的離線快取卡住了。到個人頁「帳號」按「清除本機快取並重新載入」,不必登出。

Q10. 我有 iPad / 電子紙,但版面跟桌機一樣擠?

到個人頁「顯示」打開「強制手機版面」(只在觸控裝置上顯示這張卡)。電子紙再把主題切到「電子紙」。

Q11. 答案挑戰被駁回後,能再提一次嗎?

可以,但建議先在討論串補上新證據。挑戰歷史會永久保留,「挑戰失敗」不是負面紀錄。

Q12. 我能匯出自己的資料嗎?

可以。清單頁的「匯出」給 Markdown / Anki CSV / HTML;個人頁的「答題狀態分析」給逐次作答 CSV;「備份我的紀錄」把全部紀錄打包成 zip。

Q13. AI 功能按了沒反應?

自動挖空、AI 進階搜尋、筆記標籤走站方的 Workers AI,有每日額度,額度用完會提示可隔日再試。選字工具列的「AI」用你自己的 Groq 金鑰,沒設定會引導你到個人頁輸入。

C.1 我發現了系統 Bug 或有功能建議

  1. 右上角點「回報 bug 或意見」(對話氣泡加驚嘆號的圖示)。
  2. 填 標題(一句話概括)與 內容(重現步驟、預期行為、實際行為,或單純的想法 / 建議)。
  3. 按 送出。系統會連同你的 email、目前頁面網址與瀏覽器資訊建立一個 GitHub issue,畫面會顯示 issue 編號與連結。

本系統故意維持小巧,「合作學習相關」的建議比「個人化炫技」更容易被採納。

C.2 題目有錯字、選項抄錯

題幹屬於官方考古題,原則上保留原文;請用上面的回報按鈕說明題號與正確內容,由管理員修正。認為答案有誤請走答案挑戰(§5.10),不要用回報。

C.3 加入新成員 / 移除成員

  1. 把 email 交給管理員加入 Cloudflare Access 名單。
  2. 新成員照第一章流程登入,系統自動建立帳號。
  3. 提醒他到個人資料設好顯示名稱。

C.4 管理員專屬

管理員在複習模式首頁多一顆 ＋ 加入新年份:下載 bank-ingest.skill 在自己電腦解析官方 PDF、推進暫存區、審閱後才發布;在抹片練習「投稿」分頁多一個 待審核 子分頁;題目卡上多一顆「管理員編輯正解」。技術文件在專案的 README.md 與 CLAUDE.md。
